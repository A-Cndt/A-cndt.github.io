Astronomie

Le ciel du mois : Février 2025

Série mensuelle d’observation du ciel : constellations, planètes et événements astronomiques.

Février offre un ciel riche en constellations hivernales et en planètes très visibles.

Constellations du mois

Orion (le Chasseur)

Date / visibilité : Tout le mois, toute la nuit

Description : Orion est une constellation emblématique du ciel d’hiver.

Astuces : Repère la ceinture d’Orion pour le localiser rapidement.

  • Betelgeuse
  • Rigel
  • M42 (nébuleuse d’Orion)

Taureau

Date / visibilité : Soirées de février

Description : Reconnaissable grâce aux Pléiades.

Astuces : Suivre Orion vers l’ouest pour le trouver.

  • Pléiades
  • Aldébaran

Planètes visibles

Vénus

Date / visibilité : Aube

Description : Étoile du matin extrêmement brillante.

Astuces : Visible à l’est avant le lever du Soleil.

Mars

Date / visibilité : Fin de nuit

Description : Planète rouge facilement identifiable.

Astuces : Observer dans une zone sombre.

Événements du mois

Conjonction Lune - Jupiter

Date : 6 février

Description : Rapprochement apparent Lune/Jupiter.

Astuces : Observer juste après le coucher du Soleil.

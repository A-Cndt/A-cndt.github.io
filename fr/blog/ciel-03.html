Le ciel du mois : Mars 2025

Guide mensuel du ciel : constellations, planètes et événements astronomiques.

Le mois de mars marque une transition importante dans le ciel nocturne avec des constellations printanières et plusieurs événements majeurs.

Constellations du mois

Le Lion (Leo)

Date / visibilité : Toute la nuit

Description : Le Lion est une constellation facilement reconnaissable grâce à son étoile brillante Régulus.

Astuces : Repère la forme du point d’interrogation inversé pour identifier la tête du Lion.

  • Régulus : étoile principale de la constellation
  • Triplet du Lion : M65, M66 et NGC 3628 (galaxie du Hamburger)

La Vierge (Virgo)

Date / visibilité : Après minuit

Description : Grande constellation abritant l’étoile brillante Spica.

Astuces : Suivre la courbe de la Grande Ourse pour la repérer.

  • Spica : étoile la plus brillante
  • Amas de la Vierge : vaste amas de galaxies
  • Galaxie du Sombrero : galaxie spirale emblématique

Planètes visibles en mars

Jupiter

Date / visibilité : Début de nuit

Description : Planète très lumineuse visible après le coucher du Soleil.

Astuces : Regarder vers l’ouest après le crépuscule.

Saturne

Date / visibilité : Avant l’aube

Description : Visible dans la constellation du Verseau.

Astuces : Observer un ciel dégagé vers l’est tôt le matin.

Mars

Date / visibilité : Milieu de nuit

Description : Planète rouge facilement identifiable.

Astuces : Visible dans la constellation des Gémeaux.

Vénus

Date / visibilité : Après le coucher du Soleil

Description : Objet le plus brillant du ciel nocturne.

Astuces : Visible très bas sur l’horizon ouest.

Événements du mois

Éclipse lunaire partielle

Date : 14 mars 2025

Description : Une partie de la Lune passe dans l’ombre de la Terre.

Astuces : Observer avant le lever du Soleil.

Équinoxe de printemps

Date : 20 mars 2025

Description : Jour et nuit de durée égale, début du printemps.

Passage à l’heure d’été

Date : Nuit du 29 au 30 mars 2025

Description : Avancement des horloges d’une heure.

Éclipse solaire partielle

Date : 29 mars 2025

Description : Éclipse visible dans certaines régions du globe.
